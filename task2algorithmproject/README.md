 Algorithm Analysis Project

 Objective
This project demonstrates three algorithms:
- Bubble Sort (Sorting)
- Binary Search (Searching)
- Coin Change (Greedy Algorithm)

 Algorithms
 Bubble Sort
- Time Complexity: O(n²)

 Binary Search
- Time Complexity: O(log n)

 Coin Change
- Time Complexity: O(n)

 Files
- bubble_sort.cpp
- binary_search.cpp
- coin_change.cpp
- test_cases.txt

 Conclusion
This project demonstrates sorting, searching, and greedy algorithm implementations in C++ with runtime measurement.
